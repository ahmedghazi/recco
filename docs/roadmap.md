# Roadmap

## Backlog (web app)

- [ ] **Chat on the title page** — comment and talk with the friend who sent you the title, right on its page (thread per title + sender; delivered through the relay, kept on both phones)
- [ ] **Editorial home** — the home page becomes more editorial: editor's picks, guest lists (a guest's Top 5), alongside Saved
- [ ] Bump to connect (flick at the same moment) and "Show my QR" to add a friend
- [ ] Backup: export / import everything as a JSON file (Settings)
- [ ] Notifications with the app closed (Web Push for friends)
- [ ] Accounts + sync across devices (Supabase)
- [ ] OMDb calls through the relay, key kept as a Fly secret
